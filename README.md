# lisbon-carris-delays
Predicting bus delays in the Lisbon Metropolitan Area with real-time open data

## Data source

All data comes from the open data provided by
[Carris Metropolitana](https://carrismetropolitana.pt/open-data):

- **Real-time arrivals, lines and stops:** [Carris Metropolitana API](https://github.com/carrismetropolitana/api)
- **Schedules:** official GTFS feed (`https://api.carrismetropolitana.pt/v2/gtfs`)

This is an independent project and is not affiliated with or endorsed by Carris Metropolitana.
